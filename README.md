# landslide-image-segmentation
Segmentation of landslide scar and debris by the YOLOv8-seg model and Ultralytics package
Image datatset can be downloaded in Kaggle: https://www.kaggle.com/datasets/horacelo/landslide-image-dataset
YOLO landslide image model training.ipynb : Training of the YOLO model
YOLO landslide image segmentation Apr29.ipynb: Prediction using the trainined YOLO model
best.pt: Weights of the trained YOLO model
